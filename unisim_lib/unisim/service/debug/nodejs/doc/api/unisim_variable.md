# Class UnisimVariable

This class is not construtible.

It represents a UNISIM-VP simulator variable (parameter or statistic).

## `(read-only) name: string`

Full name of the variable.

## `(read-only) description: string`

Description of the variable.

## `(read-only) type: string`

Type of the variable (either "parameter" or "statistic").

## `(read-only) dataType: string`

Data type of the variable.

## `(read-only) enum: Array of string`

The list of allowed values for the variable.

## `value: *`

The value of the variable.
