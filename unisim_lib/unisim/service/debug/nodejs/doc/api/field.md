# Class Field

This class is not construtible.

## `(read-only) name: string`

Name of the field.

## `(read-only) description: string`

Description of the field.

## `(read-only) bitOffset: Number`

Offset in bits of field within the register.

## `(read-only) bitWidth: Number`

Width in bits of field.

## `get() => Number`

Get the value of the field.

## `set(value: Number)`

Set the value of the field.
